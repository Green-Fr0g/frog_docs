# 全身遥操作指南

本指南介绍全身遥操作过程中的最佳实践。

```{admonition} 前提条件
:class: note
请先完成[快速上手](../getting_started/quickstart)、[PICO 设置](../getting_started/vr_teleop_setup)和[遥操作设置](../tutorials/vr_wholebody_teleop)
```

## 概览

全身遥操作非常非常难做好，涉及的环节很多。本指南将带你了解全身遥操作过程中必须注意的各项细节。在全身遥操作时，GEAR-SONIC 策略会**尽可能**复制你的动作，包括你的脚部动作！因此，如果不采取适当的预防措施，整个过程可能**非常吃力且危险**。

```{admonition} 安全警告
:class: danger
机器人会实时跟踪你的全身动作。请始终在机器人周围保持 3 米的净空安全区，安排一名安全员守在键盘旁随时准备按 **`O`** 进行急停，并且你自己也要随时准备通过 PICO 手柄执行急停。在上真机尝试之前，请先在仿真中反复充分练习！
```

## 遥操作会话示例

一次典型的全身遥操作会话遵循以下流程：


```{video} ../_static/teleop/teleop_session_overview.mp4
:width: 100%
```
*视频：完整启动流程 — 校准 PICO 头显、启动策略，以及机器人在龙门架上开始自主保持平衡。*

**终端 1 — MuJoCo 仿真器**（真机可跳过）：
```bash
source .venv_teleop/bin/activate
python gear_sonic/scripts/run_sim_loop.py
```

**终端 2 — C++ 部署**：
```bash
cd gear_sonic_deploy
# 仿真：
bash deploy.sh --input-type zmq_manager sim
# 真机：
# bash deploy.sh --input-type zmq_manager real
```

**终端 3 — PICO 遥操作推流端**：
```bash
source .venv_teleop/bin/activate
python gear_sonic/scripts/pico_manager_thread_server.py --manager 
```

**操作员操作**：
1. **佩戴 PICO 头显和手柄** — 确保脚部追踪器已牢固佩戴。 
2. **摆好校准姿态** — 身体直立、双脚并拢、手臂自然下垂。务必经常重新校准！！！
3. **让机器人松弛但保持站立** - 将 G1 以某种松弛方式挂在龙门架上（策略会自行启动并开始自主保持平衡）。 
4. 在手柄上**按下 A+B+X+Y** — 初始化策略并校准（进入 Planner 模式）
5. **按下 A+X** — 切换到 Pose 模式（全身遥操作激活）
6. **遥操作** — 机器人现在会镜像你的动作
7. 结束时**按下 A+B+X+Y** — 急停并退出。策略会停止！！！

## 服装要求

**关键：** 遥操作期间你**必须**穿着**紧身裤或打底裤**。

**为什么重要：**
- PICO 脚部追踪器依靠视觉追踪，需要清晰看到你的腿部/脚部动作
- 宽松、肥大或飘逸的衣物（运动裤、阔腿裤、长裙）会遮挡追踪器
- 即使短暂的追踪丢失也会导致机器人收到错误的脚部位置，从而引发踉跄或危险动作

**推荐：**
- ✅ 运动打底裤或压缩紧身裤
- ✅ 合身牛仔裤或修身长裤

**不推荐：**
- ❌ 肥大的运动裤或工装裤
- ❌ 阔腿裤或喇叭裤
- ❌ 长连衣裙或长裙
- ❌ 腿部周围任何宽松或飘逸的布料

**上半身：** 正常合身的衣物即可。避免过于肥大、可能干扰手柄追踪的袖子。 

**❗️❗️❗️务必经常重新校准** PICO 的追踪质量可能随时间变差。一旦发现性能下降，务必重新校准！另外，PICO 手柄丢失追踪时，可能会卡在坐姿/奇怪姿态上。启动遥操作策略之前，务必（通过查看 PICO 虚拟形象）确认你的被追踪动作是正确的！ 

## WiFi 延迟

```{video} ../_static/teleop/teleop_natural_movement.mp4
:width: 100%
```
*视频：演示自然行走与犹豫行走对机器人稳定性的影响 — WiFi 延迟或不自然动作造成的踉跄。*

**网络延迟应尽可能低。** 我们提供了检测延迟的工具。网络延迟会显著影响 GEAR-SONIC 策略的表现，因为机器人的动作流会在动作中途（例如行走中迈步的中途）被打断，机器人可能踉跄或失去平衡。

**最佳实践：**
- **使用私人 WiFi 路由器** 公共和学校的 WiFi 很容易出现较大延迟。 
- **尽量减少 WiFi 跳数** — 理想情况下 PICO 与部署机器处于同一局域网
- **检查延迟** — 在终端输出中监控 ZMQ 消息延迟


**预期延迟：**
- **良好：** < 10ms（有线或信号强的本地 WiFi）
- **可接受：** 10-30ms（可能察觉轻微滞后）
- **较差：** > 30ms（机器人难以跟踪平滑动作，踉跄风险增加）

**检查网络性能：**
如果消息延迟超过阈值，部署终端会显示警告。请留意类似以下的消息：
```
WARNING: High ZMQ latency detected: 45ms
```

如果持续看到高延迟警告，请先改善网络配置再继续。

## 动作方式

```{video} ../_static/teleop/teleop_walking.mp4
:width: 100%
```
*视频：行走演示 — 以自然步态进行前进、后退、奔跑和侧向移动。*

**尽量保持自然。** GEAR-SONIC 策略是用自然的人体动作训练的，因此自然地动作效果最好。动作时犹豫不决反而会导致更多踉跄！ 

**良好的动作习惯：**

1. **自然行走** — 用你平常的步态，手臂自然摆动。不要夸张，也不要试图"帮"机器人。

2. **平稳转移重心** — 迈步时像平常一样把重心从一只脚移到另一只脚。要自信！ 

3. **使用适中的速度** — 机器人可以跟踪快速动作，但先以舒适的节奏行走。等你适应之后可以加速甚至跑起来。

**常见错误：**

- ❌ **过度缓慢的动作** — 不要放慢太多！ 
- ❌ **试图迁就机器人的动作** — 不要试图去配合机器人的动作，否则机器人会反过来试图配合你，从而开始踉跄。保持自然！

**进阶动作：**

```{video} ../_static/teleop/teleop_advanced.mp4
:width: 100%
```
*视频：进阶动作 — 跪地、动态腿部动作和高难度姿态。*

基本行走适应之后：
- **转身** — 通过转动躯干并向新方向迈步来自然转弯
- **伸手** — 平滑地伸展手臂去抓取物体 
- **下蹲** — 自然地屈膝降低身体
- **侧移** — 伴随自然的重心转移向侧方迈步

## 校准最佳实践

初始校准对遥操作成功**至关重要**。

**校准姿态：**
1. **身体直立** — 目视正前方（不要低头看手柄）
2. **双脚并拢** — 双脚平行，不留缝隙。 
3. **上臂下垂** — 沿躯干两侧自然竖直下垂


**提示：**
- 按下 A+B+X+Y 后保持姿态稳定 1-2 秒
- 如果整个会话期间机器人似乎始终有偏差，请重新校准（按 A+B+X+Y 停止，然后重新开始）


## 模式切换安全

在模式之间切换时，**务必先匹配机器人当前姿态**。

**危险场景：**
1. 机器人在 Planner 模式下直立站立
2. 你正蹲着或处于另一种不同姿态
3. 你按下 **A+X** 切换到 Pose 模式
4. **机器人会剧烈地试图匹配你的蹲姿** ⚠️

**安全流程：**
1. 按下 **A+X** 之前，先观察机器人（或可视化画面）
2. 把身体调整到大致匹配机器人当前姿态
3. 然后再按 **A+X** — 切换将会平滑

**暂停功能（Menu 键）：**

```{video} ../_static/teleop/teleop_pause.mp4
:width: 100%
```
*视频：在遥操作中使用 Menu 键暂停和恢复姿态推流。*

- 按住 **Menu** 会暂停姿态推流
- **在松开 Menu 之前**，把身体调整回与机器人当前姿态匹配
- 在姿态差异很大时松开 Menu 会引发突发的危险动作

## 故障排除

### 机器人不跟踪我的动作

**可能原因：**
- 脚部追踪器未牢固佩戴或电量过低
- 宽松衣物遮挡了追踪器
- 光照条件差
- XRoboToolkit 未在 PICO 上运行或配置不正确

**解决方法：**
1. 检查脚部追踪器的佩戴位置和电量
2. 确认你穿着紧身裤
3. 改善光照（避免过亮或过暗的区域）
4. 在 PICO 头显上重启 XRoboToolkit
5. 重新校准 

### 机器人突然做出剧烈动作

**可能原因：**
- 在姿态不匹配时切换了模式
- 追踪故障或脚部追踪器被遮挡
- 网络丢包导致帧延迟

**解决方法：**
1. 恢复前仔细重新校准
2. 切换模式前务必匹配机器人姿态
3. 检查网络延迟并改善 WiFi/有线连接

### 跟踪抖动或踉跄

**可能原因：**
- 无线延迟
- IMU 漂移 
- 关节编码器漂移


**解决方法：**
1. 减少 WiFi 干扰（远离其他无线设备）
2. 重新校准机器人 

   
## 应急处置

### 急停方法

**键盘（部署终端）：**
- 按 **`O`** 立即停止

**PICO 手柄：**
- 同时按下 **A + B + X + Y**

两种方法都会立即停止策略并退出控制模式。
