ProtoMotions 更新日志
======================

未发布

在此部分记录下一次发布的内容。发布时，将已完成的条目移入对应的日期发布小节。

2026 年 8 月 12 日
-------------------------

本次发布包含以下改动：

任务控制与推理
~~~~~~~~~~~~~~~~~~~~~~~~~~

* 新增可配置的目标指令、语义朝向轴、恢复姿态重置，以及用于可靠任务采样的最小动作权重下限。
* 新增软关节限位奖励与末端执行器位置奖励，并在关节状态发散时安全终止。
* 新增离线 FK 目标观测、里程计扰动/消融路径，以及面向部署跟踪的可选参考行程前馈。

仿真器与物理
~~~~~~~~~~~~~~~~~~~~~

* 切换至公开提交 ``e7a737c`` 对应的 Newton 1.0.0，以及 IsaacLab 提交
  ``4ecd0b036da19ff6ad2bb4d621f886b63e9f6db8``
  （``v3.0.0-beta-712-g4ecd0b``）对应的 IsaacLab 3.0 /
  Isaac Sim 6.0。
* 将 MJCF 确立为机器人资产的唯一事实来源。IsaacLab 在加载时转换随附的
  MJCF，并保留多轴关节结构与元数据。
* 修复 Newton、IsaacGym 与 IsaacLab 之间的摩擦随机化及 combine 模式转换，
  包括部分区间与共享分桶。
* 改进 Newton 的分布式设备选择、关节名诊断与评估处理；统一各后端的角色摩擦默认值。
* 改进场景物体状态处理，以及四元数、重置和单环境仿真器状态行为。

训练与打包
~~~~~~~~~~~~~~~~~~~~

* 新增可配置的 Weights & Biases 项目名、训练迭代上限，以及面向多 GPU
  数据集、支持运行时分片切换的分片 MotionLib 加载。
* 新增 PyPI 与 UV 安装支持，同时保留预配置的 Torch 构建。
* 通过合并执行器配置、降低地形/动作参考/子集重置热点路径开销，提升 IsaacLab 吞吐量。
* 改进预训练模型、G1 部署和 SLURM 训练相关的快速上手与工作流文档。

模型与部署
~~~~~~~~~~~~~~~~~~~~~

* 以权威的 ``resolved_configs.pt`` 附属配置文件刷新了 G1 BONES-SEED、SMPL、SOMA
  和 MaskedMimic 预训练资产。
* 改进 ONNX 部署元数据与 MuJoCo 跟踪器测试框架，包括动作索引选择和导出的力矩上限。
* 改进 MuJoCo 与 Newton 之间预训练策略的推理兼容性。
