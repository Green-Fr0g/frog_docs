运动生成器
=================

机器人任务通常在任务空间（task-space）中以期望的末端执行器轨迹来定义，而控制动作则在
关节空间（joint-space）中执行。这自然引出了 *关节空间* 和 *任务空间* （操作空间）
控制方法。然而，使用运动控制成功执行交互任务，通常需要对机器人机械臂
及其环境都有精确的模型。尽管机械臂的模型可能足够精确，但环境的详细描述却难以获得 :cite:p:`siciliano2009force`。
由这种失配引起的规划误差可以通过在交互过程中引入 *柔顺* （compliant）行为来克服。

虽然柔顺性可以通过机器人结构被动实现（例如弹性执行器、软体机械臂），但我们更
关注以主动交互控制为核心的设计。这些方法大致分为两类：

1. **阻抗控制（impedance control）：** 一种间接控制方法，将交互过程中产生的运动偏差
   与接触力关联为一个质量-弹簧-阻尼系统，其参数（刚度和阻尼）可调。它的一个特例是
   *刚度* 控制，即只考虑位置误差与接触力之间的静态关系。

2. **混合力/运动控制（hybrid force/motion control）：** 一种主动控制方法，分别在非约束
   和受约束的任务方向上控制运动和力。在各种混合运动控制方案中，所提供的实现基于操作空间
   的逆动力学控制 :cite:p:`khatib1987osc`。

.. note::

    为了提供更丰富的运动生成器集合，我们欢迎社区贡献。如果你有兴趣，请开启一个 issue 来发起讨论。


关节空间控制器
-----------------------

力矩控制
~~~~~~~~~~~~~~

动作维度： ``"n"`` （关节数量）

在力矩控制模式下，输入动作被直接设置为前馈关节力矩指令，即在每个时间步，

.. math::

    \tau = \tau_{des}

因此，只需通过 :class:`ActuatorControlCfg` 类将执行器组的指令类型设置为 ``"t_abs"``，即可实现该控制模式。


速度控制
~~~~~~~~~~~~~~~~

动作维度： ``"n"`` （关节数量）

在速度控制模式下，需要一个比例控制律来减小当前关节速度与期望关节速度之间的误差。根据输入动作，关节力矩指令计算为：

.. math::

    \tau = k_d (\dot{q}_{des} - \dot{q})

其中 :math:`k_d` 是从配置中解析得到的增益。

只需通过 :class:`ActuatorControlCfg` 类将执行器组的指令类型设置为 ``"v_abs"`` 或 ``"v_rel"``，即可实现该控制模式。

.. attention::

    在执行速度控制时，很多情况下需要重力补偿，以确保对指令更好的跟踪。在这种情况下，我们建议
    在仿真中禁用关节体中连杆的重力。

固定刚度的位置控制
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

动作维度： ``"n"`` （关节数量）

在位置控制模式下，采用比例-阻尼（PD）控制律来跟踪期望的关节位置，并确保关节体静止在期望位置（即，期望关节速度
为零）。根据输入动作，关节力矩指令计算为：

.. math::

    \tau = k_p (q_{des} - q)  - k_d \dot{q}

其中 :math:`k_p` 和 :math:`k_d` 是从配置中解析得到的增益。

以上述最简单的形式，只需通过 :class:`ActuatorControlCfg` 类将执行器组的指令类型设置为 ``"p_abs"`` 或 ``"p_rel"``，即可实现该控制模式。

然而，考虑关节体动力学的更完整的公式为：

.. math::

    \tau = M \left( k_p (q_{des} - q)  - k_d \dot{q} \right) + g

其中 :math:`M` 是大小为 :math:`n \times n` 的关节空间惯性矩阵，:math:`g` 是关节空间
重力向量。该实现可通过 :class:`JointImpedanceController` 类获得，只需将阻抗模式设置为 ``"fixed"``。增益 :math:`k_p` 从输入配置中解析得到，而 :math:`k_d`
则通过将系统视为解耦的点质量振子来计算，即，

.. math::

    k_d = 2 \sqrt{k_p} \times D

其中 :math:`D` 是系统的阻尼比。当 :math:`D = 1` 时达到临界阻尼，:math:`D > 1` 时为过阻尼，:math:`D < 1` 时为欠阻尼。

此外，可以通过将配置中的标志 :attr:`inertial_compensation` 和 :attr:`gravity_compensation` 分别设置为 :obj:`False`，来禁用控制器中的惯性补偿或重力补偿。

变刚度的位置控制
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

动作维度： ``"2n"`` （关节数量）

在刚度控制中，采用与上述相同的公式，但增益 :math:`k_p` 是输入指令的一部分。该实现可通过 :class:`JointImpedanceController` 类获得，
只需将阻抗模式设置为 ``"variable_kp"``。

变阻抗的位置控制
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

动作维度： ``"3n"`` （关节数量）

在阻抗控制中，采用与上述相同的公式，但 :math:`k_p` 和 :math:`k_d`
都是输入指令的一部分。该实现可通过 :class:`JointImpedanceController`
类获得，只需将阻抗模式设置为 ``"variable"``。

任务空间控制器
----------------------

微分逆运动学（IK）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

动作维度： ``"3"`` （相对/绝对位置）、 ``"6"`` （相对位姿）或 ``"7"`` （绝对位姿）

逆运动学将任务空间跟踪误差转换为关节空间误差。在最典型的实现中，
任务空间（task-sace）中的位姿误差 :math:`\Delta \chi_e = (\Delta p_e, \Delta \phi_e)` 计算为期望与当前任务空间位置之间的笛卡尔距离，
以及期望与当前任务空间姿态之间在 :math:`\mathbb{SO}(3)`
上的最短距离。

利用几何雅可比矩阵 :math:`J_{eO} \in \mathbb{R}^{6 \times n}` （它将任务空间速度与关节空间速度关联起来），
我们设计控制律来获得期望的关节位置：

.. math::

    q_{des} = q + \eta J_{eO}^{-} \Delta \chi_e

其中 :math:`\eta` 是缩放参数，:math:`J_{eO}^{-}` 是雅可比矩阵的伪逆。

可以使用不同的公式来计算雅可比矩阵的伪逆：

* Moore-Penrose 伪逆：:math:`A^{-} = A^T(AA^T)^{-1}`。
* Levenberg-Marquardt 伪逆（阻尼最小二乘）：:math:`A^{-} = A^T (AA^T + \lambda \mathbb{I})^{-1}`。
* 转置伪逆：:math:`A^{-} = A^T`。
* 来自 :cite:t:`buss2004ik` 的自适应奇异值分解（SVD）伪逆。

这些实现可通过 :class:`DifferentialInverseKinematics` 类获得。

阻抗控制器
~~~~~~~~~~~~~~~~~~~~


它使用任务空间位姿误差和雅可比矩阵，通过质量-弹簧-阻尼系统计算关节力矩，模式包括
a) 固定刚度，b) 变刚度（刚度控制），
以及 c) 变刚度和变阻尼（阻抗控制）。

操作空间控制器
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

类似于任务空间阻抗
控制，但使用运动方程（EoM）来计算
任务空间力

闭环比例力控制器
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

它使用比例项
相对于末端执行器当前的力旋量（wrench）来跟踪期望的力旋量指令。

混合力-运动控制器
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

它结合了闭环力控制和操作空间运动控制来计算末端执行器的期望力矩。它使用选择矩阵来定义
非约束和受约束的任务方向。


反应式规划器
-----------------

典型的任务空间控制器不考虑运动约束，例如关节限位、自碰撞和环境碰撞。相反，
它们依赖高层规划器（例如 RRT）来处理这些
非欧几里得约束，并向控制器给出关节/任务空间路径点。然而，这些方法通常较为保守，
在接近物体时会产生不期望的减速。最近，一些不同的方法将这些约束直接合并到
优化问题中，从而为运动生成和控制提供整体解决方案。

我们目前支持以下规划器：

-  **RMPFlow (lula)：** 一种基于加速度的策略，它组合各种黎曼运动策略（RMP）来
   求解任务层次结构 :cite:p:`cheng2021rmpflow`。它能够在将末端执行器导航到目标的过程中执行动态碰撞
   避让。

-  **MPC (OCS2)：** 一种基于顺序线性二次（SLQ）规划的滚动时域控制策略。
   它通过软惩罚将各种约束整合到单个优化问题中，并使用自动
   微分来计算系统动力学、约束和代价的导数。目前，我们支持在固定机械臂和移动操作机器人上进行末端执行器轨迹跟踪的 MPC 公式。该公式
   考虑了带关节限位和自碰撞避让的运动学系统模型 :cite:p:`mittal2021articulated`。


.. warning::

    我们封装了这些反应式规划器的 Python 绑定，以批量计算机器人动作。然而，它们目前的实现基于 CPU，
    这可能会导致学习过程出现一定的减速。
