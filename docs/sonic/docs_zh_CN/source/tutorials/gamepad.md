# 使用手柄控制的动作跟踪与运动学规划器

使用 Unitree 无线手柄控制机器人，进行参考动作回放与基于规划器的移动（使用 `--input-type gamepad`）。

```{admonition} 前置条件
:class: note
请先完成[安装指南](../getting_started/installation_deploy)并编译构建项目，再继续操作。
```

```{warning}
手柄接口需要将物理 Unitree 无线手柄连接到机器人。**sim2sim 中不可用**——请先在仿真中使用[键盘接口](keyboard.md)测试。
```

```{admonition} 紧急停止
:class: danger
随时可按 **Select**（选择键）立即停止控制并退出。请始终留一只手随时准备按下 **Select**。
```

## 启动

```bash
# From gear_sonic_deploy/
bash deploy.sh --input-type gamepad real
```

## 分步操作：普通模式（参考动作跟踪）

普通模式回放预加载的参考动作。这是程序启动时的默认模式。

1. 按 **Start**（开始键）启动控制系统。
2. 按 **A** 播放当前参考动作——机器人会将其执行至结束。
4. 按 **R1** 切换到下一个动作序列，按 **L1** 切换到上一个。
5. 再次按 **A** 播放新的动作。
6. 要在动作中途停止并回到第一帧，按 **B**——机器人会暂停但不会终止策略。
7. 使用 **D-pad Left / Right**（十字键左/右）微调朝向（每次按压 ±0.1 rad）。
8. 按 **X** 或 **Y** 重新初始化基座四元数并将朝向重置为零，即机器人会将当前面朝的方向视为参考动作第一帧时的朝向。
9. 操作完成后，按 **Select** 停止控制并退出。

## 分步操作：规划器模式（实时动作生成）

规划器模式提供摇杆模拟量控制——用左摇杆控制移动，用右摇杆控制面朝方向，并可循环切换移动模式。

1. 在普通模式下按 **F1** 切换到规划器模式。终端将打印 `Planner enabled`。
2. 机器人以慢走模式（模式 1）启动。将**左摇杆前推**即可行走——移动方向根据摇杆角度相对当前面朝方向计算得出。
3. 左右拨动**右摇杆**平滑旋转面朝方向（连续，每帧 ±0.02 rad）。
4. 按 **R1** 循环切换到下一个移动模式（待机 → 慢走 → 行走 → 奔跑 → 下蹲 → 双膝跪地 → 跪地 → 待机 → …）。按 **L1** 反向循环。
5. 按住 **R2** 增大速度（站立类模式 1–3）或高度（下蹲类模式 4–6）。按住 **L2** 减小。按住期间速度/高度每帧变化 ±0.02。
6. 当左摇杆处于死区时，站立类模式自动切换为待机；下蹲/跪地模式以速度 0 保持当前姿态。
7. 要暂停，按 **B**——机器人立即重置为待机。
8. 再按 **F1** 返回普通模式，或按 **Select** 停止并退出。

## 控制参考

### 系统控制（两种模式通用）

| 按键 | 动作 |
|--------|--------|
| **Start** | 启动控制系统 |
| **Select** | 停止控制并退出（急停） |
| **F1** | 在普通 / 规划器模式之间切换 |
| **X** 或 **Y** | 重新初始化基座四元数并重置朝向 |
| **D-pad Left / Right** | 调整朝向增量（±0.1 rad） |

### 普通模式按键

| 按键 | 动作 |
|--------|--------|
| **A** | 将当前动作播放至结束 |
| **B** | 从头重新开始当前动作（停在第 0 帧） |
| **L1** / **R1** | 上一个 / 下一个动作序列 |

### 规划器模式按键

**移动：**

| 输入 | 动作 |
|-------|--------|
| **左摇杆** | 移动方向（由摇杆角度 + 面朝方向计算） |
| **右摇杆** | 面朝方向（连续旋转，每帧 ±0.02 rad） |

**模式与速度：**

| 按键 | 动作 |
|--------|--------|
| **L1** / **R1** | 上一个 / 下一个移动模式（循环 0–6） |
| **L2**（按住） | 减小速度（模式 1–3）或高度（模式 4–6），每帧 ±0.02 |
| **R2**（按住） | 增大速度（模式 1–3）或高度（模式 4–6），每帧 ±0.02 |
| **A** | 播放 / 恢复动作 |

**紧急：**

| 按键 | 动作 |
|--------|--------|
| **B** | 暂停（重置为待机） |
| **Select** | 停止控制并退出 |

## 移动模式

手柄通过 **L1** / **R1** 在 7 种模式间循环切换。使用 **L2** / **R2**（按住）调整速度或高度。

| ID | 模式 | L2/R2 调整项 | 范围 |
|----|------|---------------|-------|
| 0 | 待机（Idle） | — | — |
| 1 | 慢走（Slow Walk） | 速度 | 0.2–0.8 m/s |
| 2 | 行走（Walk） | 速度 | 0.8–1.5 m/s |
| 3 | 奔跑（Run） | 速度 | 1.5–3.0 m/s |
| 4 | 下蹲（Squat） | 高度 | 0.1–0.8 m |
| 5 | 双膝跪地（Kneel Two Legs） |  — |  — |
| 6 | 跪地（Kneel） |  — |  — |

```{tip}
横移（侧向迈步）时，建议将目标速度保持在 **0.4 m/s** 左右。横移速度过高时，侧向迈步所需的交叉腿部落足方式可能导致机器人双脚碰撞。
```

```{note}
从相邻模式进入下蹲（模式 4）时，高度会自动初始化为 0.8 m。
```
