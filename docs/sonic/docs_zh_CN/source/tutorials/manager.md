# 接口管理器（Interface Manager，一体化）

可在运行时通过热键在键盘（Keyboard）、手柄（Gamepad）和 ZMQ 输入接口之间动态切换（`--input-type manager`）。管理器（manager）同时持有所有接口，并把输入委派给当前激活的接口。你可以随时切换，无需重启程序。

```{admonition} 先决条件
:class: note
先完成[快速上手](../getting_started/quickstart.md)，使 sim2sim 循环处于运行状态。
```

```{admonition} 紧急停止（急停）
:class: danger
任何时候按下 **`O`** 即可立即停止控制并退出——无论当前激活的是哪个接口（包括手柄被选中时），该操作都有效。请始终让一只手放在键盘附近，随时准备按下 **`O`**。
```

## 启动

**Sim2Sim（MuJoCo）：**

```bash
# 终端 1 —— MuJoCo 仿真器（在仓库根目录）
source .venv_sim/bin/activate
python gear_sonic/scripts/run_sim_loop.py

# 终端 2 —— C++ 部署（在 gear_sonic_deploy/ 目录）
bash deploy.sh --input-type manager sim
```

**真机：**

```bash
# 在 gear_sonic_deploy/ 目录
bash deploy.sh --input-type manager real
```

如果打算使用 ZMQ 接口，请添加 ZMQ 相关旗标：

```bash
bash deploy.sh --input-type manager \
  --zmq-host <publisher-ip> \
  --zmq-port 5556 \
  --zmq-topic pose \
  sim
```

## 操作步骤

1. 管理器默认以 **Keyboard** 模式启动。
2. 按下 **`]`** 启动控制系统（键盘模式）。按照[键盘教程](keyboard.md)中的说明操作机器人。
3. 要切换到手柄，按下 **`Shift+2`**（输入 `@`）。终端会打印 `Switched to: GAMEPAD (safety reset triggered)`。机器人回到第 0 帧的参考动作，规划器被禁用。
4. 按照[手柄教程](gamepad.md)中的说明使用手柄控制。
5. 要切换到 ZMQ 流式传输，按下 **`Shift+3`**（输入 `#`）。此时会触发一次安全重置，终端打印 `Switched to: ZMQ`。按照[ZMQ 教程](zmq.md)中的说明使用 ZMQ 控制。
6. 要随时切换回键盘，按下 **`Shift+1`**（输入 `!`）。
7. 按下 **`O`** 可从任何接口停止控制并退出。

## 切换接口

| 热键 | 接口 | 说明 |
|--------|-----------|-------|
| **Shift+1** (`!`) | Keyboard | 默认。完整键盘控制（Normal + Planner 模式）。见[键盘教程](keyboard.md)。 |
| **Shift+2** (`@`) | Gamepad | Unitree 无线手柄。见[手柄教程](gamepad.md)。 |
| **Shift+3** (`#`) | ZMQ | ZMQ 流式传输（需要 `--zmq-host` 等旗标）。见[ZMQ 教程](zmq.md)。 |

```{tip}
构建时启用 ROS2 支持后，还可通过 **Shift+4**（`$`）使用 **ROS2** 接口。该接口要求规划器已加载，否则会回退到 Keyboard。ROS2 接口仅作为构建自定义 ROS2 控制流水线的参考实现提供，其更新力度可能不及其他接口。
```

### 切换时会发生什么

每次切换都会在**所有**受管接口上触发一次**安全重置**（而不仅仅是你要切换到的那个）。这会：

- 禁用规划器，并回到第 0 帧的参考动作
- 重置朝向与移动状态
- 禁用 ZMQ 流式传输（如果它处于激活状态）
- 避免上一接口的残留状态造成控制不连续

安全重置确保切换之后你总是从一个干净状态开始，无论之前的接口在做什么。

```{note}
全部四个接口都在启动时创建，并在切换过程中保持存活。它们的内部状态（例如手柄模式、ZMQ 连接）会被保留——出于安全考虑，只有规划器/动作状态会被重置。这意味着切换回来时，你无需重新建立 ZMQ 连接或重新配对手柄。
```

## 全局控制

这些控制在管理器层面生效，**无论当前激活的是哪个接口**。它们在传递给激活接口之前，会先被管理器拦截。

### 紧急停止（急停）

| 按键 | 操作 |
|-----|--------|
| **O** / **o** | 立即急停——即使手柄或 ZMQ 是当前激活接口也有效 |
| **F** / **f** | 报告电机温度（TTS 语音播报） |

### 柔顺度控制

这些控制全局调整手部柔顺度与抓握参数。在遥操作（ZMQ / ROS2）期间机器人双手需要与物体交互时尤其有用。

| 按键 | 操作 |
|-----|--------|
| **G** / **H** | 增大 / 减小左手柔顺度 0.1 |
| **B** / **V** | 增大 / 减小右手柔顺度 0.1 |
| **X** / **C** | 增大 / 减小最大手部闭合比例 0.1 |

```{note}
柔顺度控制是全局的——无论当前激活的是哪个接口，都会影响机器人的双手。这样即使手柄或 ZMQ 正在控制机器人的移动，你也可以从键盘调整柔顺度。
```

## 各接口专属控制

一旦某个接口激活，它的所有常规控制都按各自教程中的说明工作：

- **Keyboard**（`!`）：[键盘教程](keyboard.md)中的所有按键——T/R/P/N 控制动作，ENTER 控制规划器，WASD 控制移动等。
- **Gamepad**（`@`）：[手柄教程](gamepad.md)中的所有按键——Start、A/B、L1/R1、摇杆等。
- **ZMQ**（`#`）：ENTER 切换流式传输，未推流时用 T/P/N/R 选择参考动作。见[ZMQ 教程](zmq.md)。

唯一的例外是：
- **`O`** 始终被管理器拦截用于急停（不会传递给激活接口）。
- **`G/H/B/V/X/C`** 始终被拦截用于柔顺度控制。
- **`!/@ /#/$`** 始终被拦截用于接口切换。
