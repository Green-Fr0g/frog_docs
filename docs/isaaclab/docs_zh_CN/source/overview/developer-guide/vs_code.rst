设置 Visual Studio Code
-----------------------------

**这是可选项。使用 Isaac Lab 并不需要 VScode**

`Visual Studio Code <https://code.visualstudio.com/>`_ 已被证明是开发 Isaac Lab 过程中不可或缺的工具。Isaac Lab 仓库包含用于设置开发环境的 VSCode 文件。这些文件位于 ``.vscode`` 目录中，包括以下内容：

.. code-block:: bash

   .vscode
   ├── tools
   │   ├── launch.template.json
   │   ├── settings.template.json
   │   └── setup_vscode.py
   ├── extensions.json
   ├── launch.json  # <- this is generated by setup_vscode.py
   ├── settings.json  # <- this is generated by setup_vscode.py
   └── tasks.json


.. attention::

   以下关于设置 Visual Studio Code 的说明仅适用于 :ref:`Isaac Sim Binaries Installation <isaaclab-binaries-installation>`，
   而不适用于 :ref:`Pip Installation <isaaclab-pip-installation>`。


要设置该 IDE，请按照以下说明操作：

1. 在 Visual Studio Code IDE 中打开 ``IsaacLab`` 目录
2. 运行 VSCode `Tasks <https://code.visualstudio.com/docs/editor/tasks>`__：按下 ``Ctrl+Shift+P``，选择 ``Tasks: Run Task``，然后在下拉菜单中运行 ``setup_python_env``。

   .. image:: ../../_static/vscode_tasks.png
      :width: 600px
      :align: center
      :alt: VSCode Tasks


.. note::
   如果这是你第一次在 VS Code 中运行任务，系统可能会提示你选择如何处理警告。只需按照提示操作，直到任务窗口关闭即可。

如果一切执行正确，应该会生成以下文件：

* ``.vscode/launch.json``: 包含用于调试 Python 代码的启动配置。
* ``.vscode/settings.json``: 包含 Python 解释器和 Python 环境的设置。

有关 VSCode 对 Omniverse 支持的更多信息，请参阅以下链接：

* `Isaac Sim VSCode support <https://docs.isaacsim.omniverse.nvidia.com/latest/development_tools/vscode.html#visual-studio-code-vs-code>`__


配置 Python 解释器
----------------------------------

在提供的配置中，我们将默认的 Python 解释器设置为 Omniverse 提供的 Python 可执行文件。这一设置位于 ``.vscode/settings.json`` 文件中：

.. code-block:: json

   {
      "python.defaultInterpreterPath": "${workspaceFolder}/_isaac_sim/python.sh",
   }

如果你想使用其他的 Python 解释器（例如来自你的 conda 或 uv 环境），你需要更改所使用的 Python 解释器：在 VSCode 左下角选择并激活你选择的 Python 解释器，或者打开命令面板（``Ctrl+Shift+P``）并选择 ``Python: Select Interpreter``。

有关如何为 VSCode 设置 Python 解释器的更多信息，请参阅 `VSCode 文档 <https://code.visualstudio.com/docs/python/environments#_working-with-python-interpreters>`_。


设置代码格式化和代码检查
---------------------------------

我们使用 `ruff <https://github.com/astral-sh/ruff/>`_ 作为格式化工具和代码检查工具（linter）。
相关配置位于 ``.vscode/settings.json`` 文件中：

.. code-block:: json

   {
      "ruff.configuration": "${workspaceFolder}/pyproject.toml",
   }

ruff 代码检查工具会在你的代码中显示警告和错误，帮助你遵循 Python 最佳实践和项目的编码规范。
