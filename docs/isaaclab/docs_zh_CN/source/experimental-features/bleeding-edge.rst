欢迎来到前沿（bleeding edge）！
===============================

Isaac Lab 之所以开源，是因为我们希望发展一个开放协作的机器人仿真社区。我们相信，稳健的工具对机器人的未来至关重要。

有时新功能可能需要对 Isaac Lab 的内部结构进行大规模改动。如果这类功能在完善之前、在未获得整个社区反馈的情况下直接集成，可能会给毫无准备的用户带来严重问题。

为此，一些重要功能将以实验特性分支（Experimental Feature Branches）的形式发布。这样，社区便可以在功能完全集成之前试用并参与贡献，降低被意外新错误打乱节奏的可能性。
