传感器
=========

在本节中，我们将概述 Isaac Lab 提供的各种传感器 API。

Isaac Lab 中的每个传感器都继承自 ``SensorBase`` 抽象类，该类提供了所有传感器固有的核心功能，即提供对场景"测量值"的访问。这些测量值可以有多种形式，例如光线投射结果、相机渲染图像，甚至直接从仿真中查询的真值数据（例如位姿）。无论数据是什么，我们都可以把传感器想象成一个缓冲区，它通过查询场景来周期性地更新测量值。这个 ``update_period`` 以"仿真"秒为单位定义，这意味着即使仿真中的时间流相对于现实世界被拉伸，传感器仍会以适当的速率更新。``SensorBase`` 的设计也考虑了可向量化性，它会为克隆环境中传感器的所有副本保存缓冲区。

更新缓冲区通过重写 ``SensorBase`` 类的 ``_update_buffers_impl`` 抽象方法来完成。在仿真的每个时间步 ``dt``，所有传感器都会被查询以进行更新。在这次查询中，该传感器管理的每个缓冲区自上次更新以来的总时间都会增加 ``dt``。如果总时间大于或等于某个缓冲区的 ``update_period``，则该缓冲区会被标记为在下一次查询时更新。
